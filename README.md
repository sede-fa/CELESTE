# Requirements
- Python 3.11.x
- Numpy 1.24+
- Scipy 1.10+
- Pandas 1.5+ (+ openpyxl 3.0+ if not installed)
- Numba 0.57+ (will be changed for Jax in the future)
- CoolProp 6.5+

# 1-step Installation: 
You just want to run models (for most users)
1. in your chosen CLI tool (cmd or conda prompt etc.) enter `pip install git+https://github.com/DLR-TT-ESI-EHT/CELESTE.git` and follow instructions
2. test by entering python and type `import celeste` if no errors, installation complete
